## Context

식약처(MFDS)는 식품에 알러기 유발물질 22종(2025년 기준)을 표시하도록 의무화했습니다. 우리 식음료 OEM 고객사는 동일 라인에서 알러겐 함유/비함유 제품을 모두 생산하므로 **교차오염 위험 표시**도 함께 관리해야 합니다.

현재는 `Item.allergen_flags` Custom Field가 Small Text(쉼표 구분 자유 입력)로 되어 있어 오타와 누락이 발생합니다. 이를 정식 마스터 DocType으로 바꿔서:
- 22종 표준화 → 오타 방지
- 다국어 라벨(한/영) 지원 → 수출 대비
- "함유" / "이 제품은 ~을 사용한 제조시설에서 만들어졌습니다" 두 가지 모드 구분

## Constraints

- ERPNext core, frappe core 절대 수정 금지.
- 기존 `Item-allergen_flags` Custom Field 자체를 삭제하지 말 것 (rename 대신 fieldtype 변경). 기존 데이터를 잃으면 복구 불가.
- 패치는 한 번 실행되면 재실행 안전해야 함 (멱등). `frappe.db.exists`로 체크 후 처리.
- 모든 사용자 노출 텍스트는 `frappe._()` 처리.
- 한국어 식약처 22종은 정확한 한글 표기 사용 (오타 주의).
- 새 DocType은 `module="Food Mes Kr"`로 설정.

## Acceptance Criteria (DoD)

다음을 **모두** 충족해야 task 완료:

1. `bench --site dev.localhost migrate` 가 에러 없이 실행됨
2. 22종 알러겐이 자동으로 DB에 들어감 (Allergen List에서 22건 확인)
3. Item 화면에서 Allergens 탭이 Table 형태로 보이며, 각 행에서 알러겐 선택 + Contains/May Contain 토글 가능
4. 기존 텍스트 `allergen_flags` 데이터(있다면)가 새 테이블로 변환됨
5. 패치를 두 번 실행해도 데이터가 중복되지 않음
6. `bench --site dev.localhost run-tests --app food_mes_kr --module food_mes_kr.food_mes_kr.doctype.allergen.test_allergen` 통과
7. `bench --site dev.localhost export-fixtures --app food_mes_kr` 실행 시 fixtures/ 안에 정확히 `allergen.json`이 갱신됨
