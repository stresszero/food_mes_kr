# T4.1 — 식약처 표시기준 라벨 (Print Format)

> 그대로 복사해서 Claude Code 첫 메시지로 사용하세요.

---

## Context

식약처 「식품등의 표시·광고에 관한 법률」 시행규칙은 가공식품 라벨에 다음 항목을 의무 표시하도록 합니다:

1. 제품명
2. 식품유형
3. 영업소(제조원/판매원) 명칭과 소재지
4. 제조연월일 / 유통기한 (또는 품질유지기한)
5. 내용량 (중량·용량·개수) — 열량 정보 함께
6. 원재료명 (함량 5% 이상 또는 알러기 유발물질은 별도 표시)
7. **알러기 유발물질 표시** — "이 제품은 [알러겐]을 사용한 제조시설에서 만들어졌습니다" 별도 박스
8. 영양성분
9. 보관 방법
10. 환불·교환 정보
11. 바코드 (의무는 아니지만 사실상 필수)

수출용은 추가 항목(국가별 다름). 이번 task는 **국내 라벨**만 다룹니다.

음료 OEM의 경우 같은 내용물이라도 거래처마다 라벨 디자인이 다른데, 본 task에서는 **표준 식약처 표시 박스**(법정 필수 부분)만 만들고, 디자인 상단부는 별도 거래처 변형으로 분리합니다.

## Task

### 1) Print Format DocType 정의

위치: `food_mes_kr/food_mes_kr/print_format/kc_food_label/`
(파일: `kc_food_label.json`, `kc_food_label.html`)

대상 DocType: **Batch** (LOT 단위 라벨이 일반적이므로)

### 2) Jinja 템플릿 작성 — 식약처 박스 형식

위치: `food_mes_kr/food_mes_kr/print_format/kc_food_label/kc_food_label.html`

박스 형태 표시 (식약처 가이드 그대로):
```
┌──────────────────────────────────────────────┐
│ [제품명]      ㅇㅇㅇ                          │
│ [식품유형]    ㅇㅇㅇ                          │
│ [업소명/소재지] ㅇㅇㅇ / ㅇㅇㅇ               │
│ [유통기한]    YYYY.MM.DD까지                 │
│ [내용량]      ㅇㅇmL (ㅇㅇkcal)              │
│ [원재료명]    ㅇㅇㅇ, ㅇㅇㅇ(밀:대두 함유)    │
│ [영양성분표]  별도 박스                       │
│ [알러기 유발물질] ㅇㅇ, ㅇㅇ                  │
│ [보관방법]    실온보관(1~35℃)                │
│ [반품/교환]   구입처 또는 본사               │
└──────────────────────────────────────────────┘
```

데이터 소스:
- Batch.item → Item에서 대부분의 필드 읽음
- 영양성분: `Item.nutrition_facts` JSON
- 알러기: `Item.allergen_flags` (T1.1 결과물 활용)
- 영업소: `Company` 마스터에서 (또는 `Item.customer` OEM 거래처가 있으면 거래처 정보)
- 유통기한: `Batch.expiry_date`
- 제조연월일: `Batch.manufacturing_date`

### 3) CSS — A6, A7 등 라벨 사이즈 대응

위치: 같은 HTML 안에 `<style>` 블록.

요구:
- 기본은 A7 (74×105mm) 라벨 가정
- `@media print` 영역에서 페이지 사이즈 정의
- 폰트는 시스템 한글 sans-serif (Noto Sans KR fallback)
- 글자 크기 최소 5pt 보장 (식약처 표시기준은 10pt 이상 권장이지만 라벨 작은 경우 5pt까지 허용)

### 4) 영양성분표 부분 컴포넌트화

위치: `food_mes_kr/food_mes_kr/print_format/_partials/nutrition_table.html`

`{% include %}` 패턴으로 다른 라벨에서도 재사용.

표시 예:
```
영양성분 / 1회 제공량 100mL당
─────────────────
열량        45 kcal
나트륨      5 mg (0%)
탄수화물    11 g (3%)
당류        10 g (10%)
지방        0 g (0%)
트랜스지방  0 g
포화지방    0 g (0%)
콜레스테롤  0 mg (0%)
단백질      0 g (0%)
─────────────────
* 1일 영양성분 기준치 대비
```

### 5) 알러기 유발물질 박스 컴포넌트화

위치: `food_mes_kr/food_mes_kr/print_format/_partials/allergen_box.html`

규칙:
- "Contains" 알러겐: 별도 박스에 강조
- "May Contain" 알러겐: "혼입가능 원료 표시" 별도 박스에
- 둘 다 없으면 박스 자체 생략

### 6) ERPNext에서 Batch 화면 → "Print" 메뉴에 노출

`is_standard=Yes`로 설정되면 자동 노출. 설정 검증.

## Constraints

- **법적 정확성이 1순위**: 식약처 표시기준 위반은 행정처분 대상. 모르는 항목은 비우지 말고 "고객 확인 필요"로 placeholder 처리.
- **다국어 가능성**: 향후 영문 라벨 추가 가능성 → 텍스트 라벨은 Item에서 한/영 둘 다 받을 수 있게 설계 (Item.item_name vs item_name_en).
- **OEM 거래처 케이스**: `Item.customer_owned=1`이면 영업소 표시는 **그 거래처** 정보 기준 (제조원: 우리 회사, 판매원: 그 거래처). 둘 다 표시 의무.
- **글꼴 임베딩**: PDF 출력 시 한글 깨짐 주의. ERPNext의 wkhtmltopdf 환경에 Noto Sans CJK 설치되어 있어야 함 (요구사항 명시).
- **단가/세금 등 가격 정보는 표시하지 말 것**: 라벨에 들어가면 안 됨.
- 라벨 위변조 방지를 위한 라벨 일련번호(`Batch.batch_id`) 작은 글씨로 표시.

## Acceptance Criteria

1. Batch 상세화면 → Menu → Print → "KC Food Label" 선택 가능
2. 인쇄 미리보기에서 모든 의무 항목이 빠짐없이 표시됨
3. 알러기 박스가 Contains/May Contain 분리 표시
4. 영양성분이 Item.nutrition_facts JSON 형식 그대로 잘 렌더링
5. 만약 Item에 `customer_owned=1` 이면 제조원/판매원 둘 다 표시
6. PDF 다운로드 시 한글 깨짐 없음
7. A7 사이즈 인쇄 시 모든 항목이 박스 안에 들어감
8. 영양성분 partial을 다른 임시 Print Format에서 include해서 재사용 가능 함을 확인

4. 미리보기 스크린샷을 생성해 사용자에게 보여주세요 (`bench --site dev.localhost execute frappe.utils.print_format.download_pdf` 활용).
