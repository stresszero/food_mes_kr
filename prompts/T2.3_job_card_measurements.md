# T2.3 — Job Card 측정값 입력 (Sterilization, pH, Brix, etc.)

> 그대로 복사해서 Claude Code 첫 메시지로 사용하세요.

---

## Context

식음료 공정은 단순한 시작/완료 시각만 기록해서는 부족합니다.
**살균 공정**은 온도 × 시간이 CCP(Critical Control Point)이고, **혼합 공정**은 pH·Brix가 품질 규격이며, **충진 공정**은 충진량 편차가 표시기준 위반에 직결됩니다.

현재 ERPNext의 `Job Card`는 작업 시작/종료, 작업 인원, 산출 수량만 받습니다. 이걸로는 식약처 감사 대응이 안 됩니다.

이 task에서 Job Card에 **측정값 자식 테이블**을 붙여 작업자가 공정 중 측정한 값을 기록하고, 그 값이 자동으로 `Quality Inspection`으로 흘러가도록 만듭니다.

### 3) Server Script: 측정값 → Quality Inspection 자동 동기화

위치: `food_mes_kr/food_mes_kr/server_scripts/job_card_measurement_sync.py`

훅: `Job Card.before_save`

동작:
- 각 measurement에 대해 `measurement_type`(Quality Inspection Parameter)를 lookup
- 그 parameter가 해당 Item의 Quality Inspection Template에 등록되어 있는지 확인
- 등록되어 있다면 spec(min/max)을 가져와 `min_spec`, `max_spec`에 채우고 `is_within_spec` 계산
- `is_ccp` 플래그도 채움

훅: `Job Card.on_submit`

동작:
- Job Card에 measurements가 있으면, 자동으로 Quality Inspection을 생성/업데이트
- Quality Inspection의 `readings` 테이블에 measurement 값 복사
- inspection_type 결정 (operation에 따라 In Process / Outgoing)
- 작성된 Quality Inspection은 `status="Submitted"` 가 아닌 `"Pending"`으로 두어 검사자가 검토 후 submit

## Constraints

- 측정값은 작업자가 입력하는 만큼 **모바일/태블릿 친화 UX**가 중요. 입력 필드 크기·터치 영역을 키우는 CSS는 별도 task(T2.4)에서 다루므로 여기서는 형태만 갖추기.
- `is_within_spec`은 사용자가 직접 못 고치게 read_only.
- 한 측정 항목(예: "살균 후 온도")이 여러 번 측정될 수 있음. 즉 measurements 테이블은 measurement_type별 unique가 아니라 **(measurement_type, measured_at)** 으로 사실상 unique.
- 측정값 단위 변환 자동 처리는 하지 말 것. UOM은 표시만, 변환은 사용자 책임.
- Quality Inspection 자동 생성은 **idempotent** — 같은 Job Card를 두 번 submit해도 QI가 두 번 생기지 않게 해야 함 (이미 연결된 QI 있으면 update, 없으면 insert).
- 측정값이 0건이면 QI 생성 안 함.

## Acceptance Criteria (DoD)

1. `bench migrate` 에러 없이 통과
2. Job Card 화면에 Measurements 섹션이 보임
3. 측정 항목 추가 → 값 입력 → spec 벗어나면 행이 빨간색
4. CCP 항목이고 spec 벗어난 상태로 저장 시도 → 경고 dialog
5. Job Card submit 시 자동으로 Quality Inspection이 만들어지고 measurements가 readings로 복사됨
6. 같은 Job Card를 한 번 cancel 후 다시 submit해도 QI가 중복 생성되지 않음
7. measurements 0건일 때 QI 생성 안 됨
8. 단위 테스트:
   - `test_measurement_within_spec` — spec 안 값
   - `test_measurement_out_of_spec` — spec 밖 값
   - `test_qi_auto_creation_idempotent` — 멱등성
